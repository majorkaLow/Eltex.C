# Терминальный Pong (Структурное Программирование)

Минималистичная версия игры Pong для терминала, написанная на C с использованием только stdio и ncurses, с соблюдением строгих ограничений.

**Основные ограничения:**
- Нет динамического выделения памяти (нет malloc/free)
- Нет структур (только базовые типы данных)
- Нет указателей на функции
- Только базовые возможности C89
- Чисто процедурное/структурное программирование

## Возможности

- Двухпользовательская локальная игра
- Простая физика мяча с обнаружением столкновений
- Отображение в реальном времени через ncurses
- Подсчёт очков
- Настраиваемые параметры игры через константы
- Минимальное использование ресурсов

## Требования

- GCC или любой совместимый компилятор C99
- Библиотека ncurses (`libncurses` или `libncursesw`)
- Unix-подобная среда терминала

## Сборка и запуск

```bash
gcc -o pong pong.c -lncurses -Wall -Wextra -std=c99 # Компиляция игры
./pong                                              # Запуск игры
```

**Управление:**
- **Player 1:** `a` (вверх), `z` (вниз)
- **Player 2:** `k` (вверх), `m` (вниз)
- **Выход:** `q` | **Рестарт игры после победы/поражения:** space
